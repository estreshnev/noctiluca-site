# Noctiluca — site

Privacy policy and terms of use for the iOS game **Noctiluca**
(bundle id `com.glittertechsolutions.noctiluca`), published via GitHub Pages.

Russian is the primary language of the App Store listing, so it sits on the
bare URLs; English is served alongside it.

| Document | Русский | English |
| --- | --- | --- |
| Privacy Policy | [privacy.html](https://estreshnev.github.io/noctiluca-site/privacy.html) | [privacy-en.html](https://estreshnev.github.io/noctiluca-site/privacy-en.html) |
| Terms of Use | [terms.html](https://estreshnev.github.io/noctiluca-site/terms.html) | [terms-en.html](https://estreshnev.github.io/noctiluca-site/terms-en.html) |

Set the privacy policy URL per listing localization in App Store Connect.
Both are also linked from inside the app, following the language chosen in the
game, as App Store Review Guideline 5.1.1(i) requires.
